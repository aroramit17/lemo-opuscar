# Social styles · pick by job

Ten styles built for short-form video. Read [`../SOCIAL.md`](../SOCIAL.md) first, then the style file. Pick by **what the video must do**, not by what looks coolest.

| Style | Job | Voice | Loops | Length |
|---|---|---|---|---|
| [Kinetic Captions](kinetic-captions.md) | teach, argue, tell | required | optional | 20–45 s |
| [Listicle Countdown](listicle-countdown.md) | tips, saves, "N things" | optional | no | 20–45 s |
| [Product Teaser](product-teaser.md) | sell | optional | no | 15–30 s |
| [Text Storytime](text-storytime.md) | entertain, confessions, hot takes | optional | optional | 20–50 s |
| [Tutorial Steps](tutorial-steps.md) | how-to | recommended | no | 25–50 s |
| [Stat Flash](stat-flash.md) | authority, shock, data | optional | no | 15–35 s |
| [Before / After](before-after.md) | show results | optional | yes | 12–30 s |
| [Carousel Reel](carousel-reel.md) | professional teaching (LinkedIn) | optional | no | 20–50 s |
| [Meme Cutaway](meme-cutaway.md) | humour, brand personality | optional | optional | 8–25 s |
| [Satisfying Loop](satisfying-loop.md) | attention, mood, audio-first | none | required | 8–20 s |

Matching a job to a style:

- *"Explain my idea with my voice"* → Kinetic Captions.
- *"Launch / promote a product"* → Product Teaser.
- *"Teach a tool or workflow"* → Tutorial Steps, or Carousel Reel for LinkedIn.
- *"Make people save it"* → Listicle Countdown.
- *"Prove it with a number"* → Stat Flash.
- *"Show the glow-up"* → Before / After.
- *"Make it funny"* → Meme Cutaway or Text Storytime.
- *"Just something mesmerising"* → Satisfying Loop.

These style files are the fixed grammar (look, timing, sound, pitfalls). The story, copy, characters and visuals are yours to direct from the user's topic. Build in the project folder, never inside `social/`. Any of the 43 cinematic styles in [`../styles/README.md`](../styles/README.md) can still be applied to a social video when the user names one; layer SOCIAL.md §3–9 on top.

Machine-readable presets: [`platforms.json`](platforms.json).
